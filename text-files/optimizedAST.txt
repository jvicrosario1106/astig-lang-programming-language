AstigLang Optimizer Demo
=======================

Source → Lexer → Parser → AST → Type check → Optimizer → Interpreter

Sample files:
  1. demo-examples/heap-test.stg — Tests for heap emulator.
  2. demo-examples/heap-test-address-of.stg — Tests for heap emulator (address of).
  3. demo-examples/optimizer-dce-test.stg — Optimizer test
  4. test-case/arrays.stg — Array test
