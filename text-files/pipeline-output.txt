AstigLang Pipeline Demo
=======================

Source → Lexer → Parser → AST → Type check → Interpreter

Sample files:
  1. demo-examples/math-simple-expression.stg — Simple math: id + num, id * id, num / num, modulus, string concat
  2. demo-examples/math-complex-expression.stg — Complex math: nested ops, function calls, arrays, records, comparisons
  3. demo-examples/logical-op-test.stg — Boolean expressions: jejemon AND, OR, NOT
  4. demo-examples/array-test.stg — Array literals, index read/write, scan
